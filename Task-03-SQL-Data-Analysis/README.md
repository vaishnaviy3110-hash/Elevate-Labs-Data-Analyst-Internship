# Task 3 - SQL for Data Analysis

## Elevate Labs Data Analyst Internship

This is my Task 3 submission for the Data Analyst Internship.

### Objective

The aim of this task was to use SQL to get useful information from an e-commerce database.

### Tools Used

- MySQL
- MySQL Workbench

### Database

I used a simple e-commerce database containing:

- Customers
- Products
- Orders

### SQL Topics Used

In this task, I practiced:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- SUM()
- AVG()
- COUNT()
- HAVING
- VIEW
- INDEX
- EXPLAIN

### Analysis Performed

Some of the questions answered using SQL were:

1. View all orders.
2. Find orders with quantity greater than 1.
3. Sort orders by quantity.
4. Find revenue by category.
5. Find the average order value.
6. Find total revenue and total orders.
7. Find the customers who spent the most.
8. Find customers who spent more than 20,000.
9. Find orders above the average order value.
10. Find the number of orders for each customer.
11. Find customers who have not placed an order.
12. Create and use a view for order details.
13. Create an index and use EXPLAIN.
14. Use RIGHT JOIN to show products and their order count.
