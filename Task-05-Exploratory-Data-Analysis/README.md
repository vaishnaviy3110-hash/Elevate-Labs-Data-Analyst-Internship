# Task 5: Exploratory Data Analysis (EDA) — Titanic Dataset

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset to identify patterns, trends, relationships, and anomalies related to passenger survival.

## Objective

To extract meaningful insights from the Titanic dataset using statistical analysis and data visualization techniques.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The Titanic dataset contains information about 891 passengers and 12 variables, including:

- Passenger class
- Gender
- Age
- Fare
- Survival status
- Number of siblings/spouses
- Number of parents/children aboard

## Analysis Performed

The following analyses were performed:

- Dataset overview and statistical summary
- Missing value and duplicate analysis
- Gender distribution
- Passenger class distribution
- Survival analysis by gender
- Survival analysis by passenger class
- Age distribution and outlier analysis
- Fare distribution and outlier analysis
- Age vs Fare relationship
- Correlation heatmap
- Pairplot analysis
- Multivariate analysis using gender and passenger class

## Key Findings

- Female passengers had a significantly higher survival rate than male passengers.
- First-class passengers had the highest survival rate.
- Third-class passengers had the lowest survival rate.
- Most passengers paid relatively lower fares.
- Fare contained several potential high-value outliers.
- Passenger class and fare showed a noticeable relationship.
- Gender and passenger class together showed strong differences in survival outcomes.

## Deliverables

- `Task_5_EDA_Titanic.ipynb` — Exploratory Data Analysis notebook
- `Task_5_EDA_Report.pdf` — PDF report containing analysis, visualizations, observations, and conclusions
- `titanic.csv` — Dataset used for analysis

## Conclusion

The analysis demonstrates how exploratory data analysis can be used to identify important patterns and relationships in real-world datasets. Gender and passenger class were found to be important factors associated with Titanic passenger survival.
